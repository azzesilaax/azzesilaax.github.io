Web Design Evaluation & Analysis

Example 1: The Appealing Website (Spotify Web Player)

a. What is the URL of the website?
https://open.spotify.com
b. Does this page use tables? If so, for what purpose?
No, the page does not use traditional HTML tables for its layout. Instead, it uses modern CSS layout techniques (like Flexbox and Grid) to organize content, grids of music albums, and playlists.
c. Does this page use CSS? If so, for what purpose?
Yes, it uses advanced CSS heavily. It is used for the dark mode aesthetic, vibrant gradient backgrounds, smooth hover animations on buttons/cards, typography configuration, and creating a responsive layout that looks great on both mobile and desktop screens.
d. Is this page appealing or unappealing? List three reasons for your answer.
It is highly appealing. The reasons are:
  • The dark theme combined with vibrant neon colors creates an energetic, modern, and immersive atmosphere suited for music lovers.
  • The visual hierarchy is clear; large typography and high-quality album arts immediately capture attention.
  • The interface is highly intuitive with interactive element animations, making navigation feel smooth and seamless.

Example 2: The Less Appealing Website (Apple Music Web Player)

a. What is the URL of the website?
https://music.apple.com
b. Does this page use tables? If so, for what purpose?
No, it does not use HTML tables for layout purposes. Like Spotify, it relies on modern CSS structures to arrange its information sections.
c. Does this page use CSS? If so, for what purpose?
Yes, it uses CSS extensively. It is used to maintain Apple's strict corporate branding: clean layouts, massive whitespace management, standard sleek fonts, subtle shadows, and minimalist grid alignments.
d. Is this page appealing or unappealing? List three reasons for your answer.
It feels more unappealing compared to Spotify. The reasons are:
  • The design relies heavily on plain white backgrounds and sterile corporate layouts, which feels too clinical, cold, and less exciting for a music platform.
  • The excessive use of empty whitespace forces the user to scroll endlessly just to see basic information.
  • It feels more like a static product advertisement page rather than an engaging, dynamic multimedia community.
e. If this page is unappealing, what would you do to improve it?
To improve the Apple Music page, I would introduce a dynamic dark mode option to make the album arts pop out more. I would also reduce the oversized whitespace between sections to make the content more compact, and incorporate fluid, engaging micro-animations to enhance user interaction.
